# 技能系统职责与代码约定

本文约定技能及关联效果的职责、引用归属和协作契约，适用于新增、修改和审阅。

## 职责分工

| 对象 | 职责 |
| --- | --- |
| `SkillDefinition` | ID、名称、静态描述、图标、共鸣类型、技能参数及直接下游引用；通过 `CalculateStats(...)` 计算自己拥有的数值，不生成显示文本 |
| `Skill` | 持有所属 Unit，提供运行条件、选择目标、创建及清理效果实例；组合本层与下游的效果描述 |
| `SkillHandler` | 管理所属 Unit 的技能集合、生命周期、能量和施放队列，不负责创建技能或绑定 Owner |
| `Zone` / `Projectile` | 封装自身效果配置，处理范围或命中；委托 Definition 计算数值，通过 `DescribeEffect(...)` 描述自身效果 |
| `BuffDefinition` / `Buff` | 前者保存静态配置并通过 `CalculateStats(...)` 计算数值；后者保存本次施加的来源、状态和数值快照，并通过 `DescribeAppliedEffect()` 描述已施加效果 |
| `BuffHandler` | 去重、重施、队列提交、计时及触发派发 |

## 配置与引用归属

- 引用跟随效果职责：`SkillDefinition → Zone/Projectile Prefab → BuffDefinition`。技能直接施加 Buff 时，由 SkillDefinition 直接引用 BuffDefinition。
- 每层封装自己的配置与状态，通过直接下游委托访问效果，不越级读取或代管内部细节；同一配置只保留一份，不为分层刻意新增中转类型。
- `Skill` 通过对外只读的 `Unit Owner` 使用单位公开 API；通用敌我及范围查询使用工厂赋予的只读 UnitManager，不通过 Owner 获取服务。具体目标选择策略由技能决定，Owner 作为来源单位参数。
- `Unit.TryGetClosestEnemyInAttackRange` 使用缓存的最近活动敌人，并计入双方体积；不等同于重新搜索、按中心距离判断的 `UnitManager.FindClosestEnemyInRange`。
- 查询型效果在 Prefab 上配置 UnitManager，初始化只设置来源与本次效果状态，不从 caster/owner 获取服务。

## 创建与装配

1. Cell 仅保存构建数据。`UnitFactory` 使用配置的 `SkillFactory` SO，根据技能 Cell 的 Definition 和等级创建技能。
2. `SkillFactory.Create` 返回前赋予 Definition 和 UnitManager，不绑定 Owner 或注册到单位。
3. `Unit.AddSkill` 先绑定 Owner，再将技能登记到 SkillHandler。调用流程保证实例有效、每个实例只属于一个单位、同类型不重复添加；登记入口不重复校验或静默去重。
4. 所有技能添加后，设置完整共鸣计数，最后调用 `CompleteAssembly`，保持被动效果应用时序。技能绑定完成后才参与描述、生命周期和施放。

`SkillHandler` 构造时接收所属 Unit，用于事件中的 owner 身份，并在能量结算时读取实时每秒能量。

## 计算与描述

- **数值归 Definition**：公式通过 `CalculateStats(...)` 返回数值及拆解，使用具名元组或小型结构，不生成显示文本；运行实例不重复实现公式。单字段结构需说明用途，不引入通用 Stats 框架。
- **静态信息直接读配置**：名称和静态 `Description` 从对应 Definition 读取，不依赖运行实例，也不维护重复硬编码。
- **动态描述归实例**：实例通过 `DescribeEffect(...)` 组合静态文案、本层计算结果与下游描述；格式化留在此流程。Definition 不实现 `DescribeEffect(...)`，描述与执行使用相同配置和计算入口。
- **Prefab 描述无副作用**：可直接调用 Prefab 组件的描述方法，只读取配置和显式参数，不依赖初始化或施法者等运行状态，无需创建场景实例。
- **已施加效果使用快照**：Buff 的 `DescribeAppliedEffect()` 使用施加时保存的数值，不随当前共鸣重新计算。技能直接施加 Buff 时，效果描述仍委托对应 Buff 实例，不在 BuffDefinition 中拼装文本。

典型委托：

```text
Skill.DescribeEffect()
  ├─ SkillDefinition.CalculateStats(运行条件)
  └─ ZonePrefab.DescribeEffect(运行条件)
       └─ BuffDefinition.CalculateStats(运行条件)
```

## 生命周期与校验

- 模板命名为 `zonePrefab` / `projectilePrefab`，运行实例命名为 `zoneInstance` / `projectileInstance`；创建者明确实例和订阅的清理责任。
- `Initialize` 建立本次运行状态，激活和停用负责生命周期；明确数值快照时点，不擅自改动等级流程。临时固定使用首级配置时留下 TODO。
- Buff 集合通过 Handler 队列变更；明确来源身份、重施、叠加、到期、伤害类型及施加时序，处理递归伤害和死亡收尾。
- 全局技能释放事件由 UnitManager 广播，活动 Unit 接收并交给自身 BuffHandler，由 Buff 决定响应；Manager 不承担 Buff 规则。
- 技能参数归具体 SkillDefinition；无专属参数时可使用基类。SkillFactory 每个 ID 必须有唯一创建映射、匹配的 Definition 类型及对应资产。
- 引用、ID、类型和数值在配置期校验，运行时不以默认值掩盖错误；引用归属变化时同步检查资产。
